# Language Policy

## Default Language

Generated documents and Harness artifacts must be written in Vietnamese by default.

This includes:

- plans
- contracts
- reports
- summaries
- backlog proposals
- project documentation
- README files
- architecture notes
- testing notes
- implementation notes

## Preserve Technical English

Keep English unchanged when it is technically meaningful or must remain exact:

- code
- commands
- file paths
- branch names
- environment variables
- package names
- framework/library names
- API fields
- schema keys
- config keys
- copied logs
- copied errors
- stack traces
- conventional commit prefixes

Do not translate identifiers, filenames, public APIs, package names, config keys, or commands.

## `run.yaml`

Keep YAML keys in English. Human-readable notes or decisions may be written in Vietnamese.

## Tool Output

When using tool output as evidence, copy it exactly. Add Vietnamese explanation before or after the copied output when helpful.
